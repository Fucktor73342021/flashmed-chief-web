🏪 Pharmacy Charges (Deducted from Pharmacy Payout)

GST is automatically added on top. Current law: 8%
Applied on seller net amount. Default: 1%
Applied on gross customer payment. Default: 0.1%
Applies to commission, platform fee, delivery margin. Law: 18%

👤 Customer Charges (Added to Customer's Bill)

GST (18%) added on top. Customer sees GST-inclusive price.
Charged only on Cash On Delivery orders. Default: ₹30
Charged per Blood SOS request. Default: ₹399

🛵 Delivery Partner Deductions (Deducted from Rider Payout)

Retained from delivery slab fee. Default: ₹5 (GST: ₹5.90 effective)
Retained from each night/rain/cold-chain surcharge. Default: ₹5

🗺️ Per-Km Delivery Rate (Customer-Facing)

Set to 0 to keep the legacy distance-slab pricing (≤1km=₹30, ≤2km=₹40, etc).
Set > 0 to switch to dynamic per-km rate — customer pays ₹X × distanceKm (pre-GST, GST added on top).

e.g. 15 → 2 km order: ₹30 base → ₹35.40 incl. GST. 0 = use legacy slabs

🧑‍🦺 Delivery Boy Earning Per Km

Set to 0 to use the legacy formula: rider earns base − platform cut.
Set > 0 to pay rider a flat per-km rate regardless of slab. Must be less than the customer charge per km.

e.g. 12 → 2 km order: rider earns ₹24. Must be < deliveryChargePerKmBase. 0 = legacy formula

🎁 Delivery Charge Waiver Offers

Set the minimum purchase price (quoted by pharmacy) for each distance slot to unlock free delivery.
Leave 0 to disable waiver for that slot. Each km slot is fully independent.
